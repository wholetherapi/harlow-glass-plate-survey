# Harlow Glass Plate Survey — digitisation package

Digitisation package for the Harlow Glass Plate Survey (FMA-HGP-1894), released to the public on 2026-08-30.

## What is in this package

- `manifests/batch-01.csv`, `batch-02.csv`, `batch-03.csv` — item-level capture manifests covering 1,842 glass plate negatives
- `metadata/descriptive.csv` — descriptive metadata exported from the collection catalogue
- `scripts/verify_checksums.py` — checksum verification for the preservation masters
- `docs/capture-log.md` — camera, lighting and handling notes from the imaging studio

## Using the package

Preservation masters are held on the archive store; the manifests and metadata in this repository are enough to request copies through the reading room. Items are cited by plate number and batch.
